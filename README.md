# 基于DDS的多功能波形发生器

## 项目概述
本项目实现一个基于直接数字合成（DDS）技术的多功能波形发生器，能够生成正弦波、方波、三角波和锯齿波，并支持频率、幅值和相位的程控调节。

## 功能特性
- 输出波形：正弦波、方波、三角波、锯齿波
- 频率调节：通过按键或串口指令
- 幅值控制：可编程幅值调节
- 相位偏移：支持相位调节

## 项目结构
```
/workspace/
├── src/          # 源文件目录
├── sim/          # 仿真文件目录
├── ip/           # IP核目录
└── docs/         # 文档目录
```

## DDS原理
直接数字合成（DDS）技术通过相位累加器、波形ROM和数模转换器实现波形生成。

## 使用方法
1. 使用Vivado或Quartus打开项目
2. 编译综合设计
3. 下载到FPGA开发板
4. 通过按键或串口控制波形参数
